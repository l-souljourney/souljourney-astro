# Docs Archive

这里存放 `v2.3.0` 整理后保留下来的历史材料。

## 目录说明

- `history/`
  - 已完成阶段的迁移记录、审计报告、部署测试记录、治理基线
- `plans/`
  - 已完成、失效或被新流程取代的历史计划文档
- `reference/`
  - 对后续排查或回顾仍有参考价值，但不再属于当前活跃交付面的资料

## 归档原则

- 归档不代表删除价值，只代表不再作为当前迭代的主参考
- 需要回看旧阶段设计时，优先从这里查
- 当前开发以 `AGENTS.md`、`docs/README.md` 的现行工程合同和已确认 Issue 为准；历史 task 不再作为执行入口。
